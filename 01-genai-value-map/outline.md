# D1-1 · GenAI 能為公司做什麼？

> 依據：`planning/slide-plan/D1-value-and-tooling.md` 的 D1-1。**狀態：講師以 /goal 指示自動核准（2026-11-23）**。
> 時間：2 小時。**不教**：任何模型的程式碼（從 D1-2 開始）；Agent、工具呼叫、MCP、RAG（屬於後續 Agent 模組）。

## 1. 學員假設與學習目標

- **學員**：已完成 Vibe Coding（提示詞、Specify→Iterate）、ML（邏輯斯迴歸，ML pp.42–43）、DL（CNN 分類，DL pp.38–55；生成式 AI 概論，DL pp.80–81）。
- **不教**：推導、程式碼、Agent。

學完後，學員能夠：

1. **區分**判別模型與生成模型，用公司的例子說明。
2. **說明**生成模型學的是資料分布 p_data，以 p_θ 近似並抽樣；提示詞是條件 p(x|y)。
3. **定位** 2026 年主要的生成模型家族，以及開放權重與封閉 API 的差別。
4. **評估**一張需求單的價值、可行性、資料、風險，並決定 API 或開放權重（用例畫布）。

## 2. 概念地圖

| 概念 | 白話定義 | 解決的問題 | 先備 | 例子 | 常見誤解 |
|---|---|---|---|---|---|
| 判別 vs 生成 | 回答「是什麼」vs 畫出「一個新的」 | 分清楚哪些需求單需要生成模型 | ML pp.42–43、DL CNN | 瑕疵分類 vs 畫新電路板 | 生成模型只是比較大的分類器 |
| p_data／p_θ | 真實資料的分布／模型學到的分布 | 「生成」到底在學什麼 | DL pp.80–81 | 產品散布圖 | 模型把訓練資料拼貼 |
| 條件 p(x｜y) | 在條件 y 下的分布 | 提示詞為何有用 | Vibe 01 提示詞 | 藍色 vs 白色耳機 | 提示詞是指令，不是條件 |
| 四面向評估 | 價值×可行性×資料×風險 | 先做哪一張 | — | 用例畫布 | 只看技術可不可行 |
| API vs 開放權重 | 用廠商服務 vs 自己跑 | 成本、隱私、控制 | — | 客服單有個資 | 開放權重一定比較便宜 |
